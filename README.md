# Dataset-Quality-Analyzer
<br>A comprehensive machine learning-powered tool for automatically assessing and predicting dataset quality. This project helps data scientists and ML engineers quickly evaluate whether their datasets are ready for machine learning tasks or require preprocessing.
<br>The Dataset Quality Analyzer is an end-to-end system that analyzes datasets across multiple quality dimensions and provides actionable insights. It uses a trained Random Forest classifier to predict dataset quality and offers a user-friendly web interface for real-time analysis.
<br> ***Features***
<br>***Automated Quality Assessment:** Analyzes 30+ quality metrics across 6 major categories*
<br>***ML-Powered Predictions:** Uses Random Forest classifier for accurate quality classification*
<br>**Interactive Web Interface:** Streamlit-based frontend for easy dataset uploads and analysis*
<br>***Comprehensive Metrics:** Evaluates missing data, outliers, skewness, correlation, and more*
<br>***Actionable Recommendations:** Provides specific preprocessing suggestions based on detected issues*
